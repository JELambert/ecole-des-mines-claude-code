# École des Mines — Claude Code Guest Lecture

Friday 2026-05-22 · ~60 min · Saint-Étienne · invited by Elise for the Texas healthcare-admin cohort traveling with her.

## What this repo is

A self-contained handout for a one-hour live session about using AI coding tools (Claude Code in particular) without being a software engineer. The talk is *about* what AI coding means for non-coders who run clinics, and the repo gives the audience everything they need to go home and try it themselves.

**No software is shipped.** The dashboard the audience watches me build live during the talk is *generated by Claude Code from the prompts in `docs/`* — not pre-committed code. That's deliberate: the point is that they can do this too.

```
data/      The synthetic Sentinel Health pilot CSV (250 rows × 26 cols)
slides/    Marp markdown deck → PDF/HTML
docs/      Numbered guides — analyze the data, build the dashboard, update it,
           git/GitHub primer, what Claude Code is
scripts/   Build helper for slides (Marp → PDF)
PLAN.md    The model — context for the talk
```
